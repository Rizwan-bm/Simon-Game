# 🎮 Simon Game

A fun, interactive memory game developed using HTML, CSS, and JavaScript. Follow the color patterns, test your memory, and challenge yourself to reach higher levels!

## 🌐 Live Demo

🔗 https://rizwan-bm.github.io/Simon-Game/

## ✨ Features

- 🎨 Colorful and attractive game interface
- 🧠 Memory and pattern recognition gameplay
- 🔄 Randomly generated color sequences
- 📈 Increasing difficulty levels
- ⚡ Interactive animations and sound effects (if implemented)
- 💻 Simple and user-friendly controls

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 How to Play

1. Start the game.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the colored buttons.
4. Remember the pattern as it gets longer.
5. Try to reach the highest level possible!

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Rizwan-bm/Simon-Game.git
```

Open the project folder in VS Code and launch `index.html` using your browser or the Live Server extension.
